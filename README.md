## 使用原则（必须遵守）

1. **仅用于合法授权场景**。下载、Root、自动化、扫描等操作必须在自己拥有或已获书面授权的设备/系统上进行。
2. **免费 ≠ 无限制**。多数工具有额度、许可证或商用限制，商用前务必查官方许可证。
3. **拒绝「先交钱」项目**。正规免费工具不要求押金、激活费、加盟费。
4. **收益预期理性**。闲置带宽/GPU 挂机多为零花钱级别，不存在「挂机月入过万」的稳定模式。
5. **平台规则优先**。游戏自动化、批量发布、自动互动等极易违反用户协议，导致封号。

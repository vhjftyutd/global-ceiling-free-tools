# 闲置资源变现 · 带宽与 GPU 挂机

> 核心原则：正规工具全程免费使用，不交押金；收益为补充零花钱级别；严格遵守运营商协议与数据安全。

## 一、闲置带宽类（适合家庭宽带）

### 国内优先

**《网心云电脑宝》**  
迅雷网心云官方工具，完全免费。共享闲置带宽、存储与计算资源，智能调度不影响日常使用。支持配置磁盘占用，每周二提现。普通 300M 宽带月收益多在几十到两百元区间，大上行更高。国内用户提现最便捷。

其他国内可参考：国鲸宝、林氪云等（以官方最新说明为准）。

### 海外带宽共享

| 工具 | 特点 | 提现门槛参考 |
|------|------|--------------|
| Honeygain | 全球用户量大，多平台支持，仅共享闲置带宽 | 约 20 美元（PayPal），加密可更低 |
| Pawns.app | 带宽 + 问卷叠加，门槛较低 | 约 5 美元 |
| EarnApp | 按 IP 结算，部分地区单价较高 | 约 2.5 美元 |
| PacketStream | 老牌稳定，可与其他平台同时挂 | 约 5 美元 |

**注意**：多平台可叠加，但收益受地区、上行带宽、在线时长影响极大。不要租机房 IP 专门挂机，租金往往覆盖不了收益。

## 二、闲置 GPU 算力类

**《GamerHash AI》**  
适合 NVIDIA 独立显卡。闲置时自动承接 AI 推理任务，启动游戏自动暂停让出性能。收益可兑换 Steam 激活码、礼品卡或加密货币。12G 显存可参与部分任务，更高显存更有优势。

**《Talos》**  
开源 GPU/CPU 共享，可绑定本地 Ollama，隐私友好，适合开发者。

**《EverXCloud》等**  
可自主定价出租 GPU，平台对接客户。注意数据隔离，不要在出租机上放个人文件。

## 三、收益最大化与合规要点

1. 开启光猫 UPnP 或合理设置可减少 NAT 损耗。
2. 保持较长在线时长，夜间流量高峰更有利。
3. **运营商协议**：家用宽带禁止擅自转租用于经营性用途，大流量可能被限速。建议控制月上行流量，做好设备隔离。
4. 所有正规工具不收取押金、激活费、加盟费。先交钱 = 诈骗。
5. 收益预期必须理性：普通家庭宽带多为每月几十到两百元；GPU 取决于型号、电价、出租率。

## 四、快速选型

| 资源情况 | 首选 |
|----------|------|
| 国内宽带，想提现方便 | 网心云电脑宝 |
| 海外宽带 / 多设备 | Honeygain + Pawns.app 等组合 |
| 有 NVIDIA 独立显卡 | GamerHash AI 或开源共享方案 |
| 想自主定价出租 | EverXCloud 类平台 |
